01 · Why it matters

Synthetic data usually stops at generation. DataEvolver keeps improving it.

The system gives the reviewer real authority over rendering quality. Semantic feedback such as floating objects, flat lighting, color drift, or broken geometry is translated into bounded scene actions.

Goal-driven loop agents

Each round observes rendered outputs, diagnoses quality issues, and chooses one targeted repair action instead of relying on static thresholds alone.

Scene-aware 3D rendering

Objects are inserted into real Blender scenes with ground detection, HDRI environment control, camera consistency, and preserved lighting context.

Training-ready modalities

The pipeline exports RGB targets, masks, depth and normal proxies, geometry metadata, scene graphs, and validation traces for downstream learning.

02 · Pipeline

From prompt expansion to dataset export.

DataEvolver connects language expansion, image generation, segmentation, 3D reconstruction, scene rendering, VLM review, and controlled feedback into one repeatable build process.

Stage 1

Text Expansion

LLM expands seed concepts into detailed object prompts.

Stage 2

T2I Generation

Qwen-Image-2512 creates 1024 by 1024 object images.

Stage 2.5

Segmentation

SAM3 extracts foreground RGBA masks for reconstruction.

Stage 3

3D Mesh

Hunyuan3D-2.1 reconstructs textured GLB assets.

Stage 4

Scene Render

Blender places each asset in realistic environments.

Stage 5

VLM Loop

Review, apply action, re-render, and stop only on keep.

03 · Core innovation

A closed loop that turns visual criticism into render control.

The action space is intentionally atomic. Lighting, object pose, scene environment, and material parameters change within bounded ranges, while anti-oscillation control prevents parameter thrashing.

RenderScene-aware RGB, mask, depth, normal, and geometry metadata.
ReviewVLM evaluates object integrity, realism, consistency, and visual fit.
ActAgent selects one bounded repair from 24 structured atomic actions.
KeepAccepted samples become training-ready records with traceable quality evidence.

08 · Get started

Clone the project and run the loop on a Linux GPU server.

The pipeline expects Blender, CUDA-capable hardware, and model paths configured in the stage scripts and dataset profile configs.

git clone https://github.com/PRIS-CV/DataEvolver.git
cd DataEvolver

# Full pipeline
bash pipeline/run_all.sh

# VLM review loop monitor
python scripts/run_scene_agent_monitor.py \
  --root-dir /path/to/run \
  --gpus "0,1,2" \
  --blender /path/to/blender \
  --meshes-dir pipeline/data/meshes
